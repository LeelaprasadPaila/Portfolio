# 🌌 Paila Leela Prasad - AI Architect Portfolio

A premium, full-stack parallax portfolio ecosystem. Powered by **React**, **Node.js**, and **MongoDB**.

---

## 🏛️ Project Structure
- **`/parallax-portfolio`**: Performance-optimized React frontend with GSAP animations.
- **`/backend`**: Node.js & Express API engine with secure MongoDB persistence.
- **`index.html`**: Root project portal (resolves GitHub 404).

---

## 🚀 One-Click Quickstart (Local)
Run both backend and frontend concurrently:
```bash
cd parallax-portfolio
node dev-start.js
```
- **Frontend**: [http://localhost:5174](http://localhost:5174)
- **Backend API**: [http://localhost:5000](http://localhost:5000)

---

## 🌐 Production Deployment (Render)
This project is optimized for deployment on Render.
Follow the **[Step-by-Step Render Guide](RENDER_WALKTHROUGH.md)** to:
1.  Connect your MongoDB Atlas cluster.
2.  Deploy the Backend Web Service.
3.  Deploy the Frontend Static Site.
4.  Configure Environment Variables (`VITE_API_URL`, etc.).

---

## 🔐 Admin Terminal
Manage your content dynamically through the Secure Access Gateway:
- Go to `/admin` in the portfolio.
- Authenticate with your backend credentials.
- Add/Edit/Delete **Projects**, **Certificates**, and **Internships** in real-time.

---

### 🎨 Technologies Used
- **Frontend**: React, GSAP, CSS Animations, Vite.
- **Backend**: Node.js, Express, Multer (File Uploads), Mongoose.
- **Database**: MongoDB (Persistence).
- **Hosting**: Render (Web Service & Static Site).
